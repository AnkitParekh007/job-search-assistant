## Bugs

Open a GitHub Issue with the **Bug report** form. Include macOS version, CPU architecture, app version (`0.1.0` / commit), sanitized logs, and reproduction steps.

**Never** post credentials, full resumes, private employer correspondence, or tracker rows with personal data.

## Questions

Use GitHub Issues with a clear question title, or GitHub Discussions once enabled by the maintainer (see `docs/discussions-setup.md`).

## Feature requests

Use the **Feature request** form. Explain the problem before the solution.

## Security

See [SECURITY.md](./SECURITY.md) — do not file public issues for vulnerabilities.

## Upstream engine

Issues in slash-command behavior, portal scrapers, or LaTeX templates may belong in [ai-job-search](https://github.com/ai-job-search-dev/ai-job-search) rather than this desktop shell.
