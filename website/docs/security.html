Security model

How the desktop app keeps you in control.

  • Human approvals — write/exec tools never auto-approve; no --dangerously-skip-permissions.
  • Local files — tracker, archives, and profile stay on disk in your workspace.
  • No stored credentials — Claude / Gmail / Notion auth remains in Claude Code.
  • Safe process spawn — argv vectors only; untrusted text reaches Claude as message content.
  • Path guards — workspace joins reject .. and absolute escapes.
  • Destructive resets — /reset needs confirmation in the app and again upstream.
  • No telemetry backend — network use is Claude Code and what upstream workflows fetch.
Profile is personal data. Don’t push your workspace profile to a public fork. Upstream gitignores tracker and tailored application archives.
