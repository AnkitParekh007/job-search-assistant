Quickstart

Get from install to a shortlist in one sitting.

  1. Install the macOS app Download from Releases or build with npm run tauri build. First launch may need right-click → Open.
  2. Install Claude Code and sign in brew install --cask claude-code, then run claude once so the CLI is authenticated.
  3. Point at your workspace Onboarding asks for your ai-job-search checkout. Change it later in Settings.
  4. Check Dependencies Settings → Dependencies should show Claude, Python ≥ 3.10, and LaTeX ready for PDF compile.
  5. Run profile setup Import a CV or answer the guided interview via /setup from onboarding or Profile.
  6. Discover → Rank → Apply From Workflows or the Jobs screen: scrape new roles, rank them, then open Studio with a posting.
Runs cost Claude usage. Every workflow uses your Claude plan or API credits. Nothing is submitted to employers for you.
