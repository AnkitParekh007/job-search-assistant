What you need on the Mac

The app is a shell. Claude Code and your upstream workspace do the real work.

  • Claude Code CLI, signed in — runs every AI workflow (uses your Claude plan or API credits).
  • Python ≥ 3.10 for upstream tools (Homebrew python@3.12 recommended).
  • BasicTeX (LuaLaTeX / XeLaTeX) to compile CV and cover-letter PDFs.
  • ai-job-search workspace checked out locally — the unmodified upstream source of truth.

Optional: poppler for ATS text checks; Bun only if you install community portal CLIs.
