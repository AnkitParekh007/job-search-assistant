# Interview preparation

## What works today

- Launch `/interview` from the Pipeline drawer or Workflows.
- Claude Code builds a stage-specific prep pack from the archived posting and your documents; roleplay on request.
- Output lands in the application archive as prep notes (upstream conventions).

## What is not built yet

- Dedicated distraction-free interview mode UI.
- Saved practice-history screen.

These are listed in [`IMPLEMENTATION-PLAN.md`](../apps/macos-apple-silicon/docs/IMPLEMENTATION-PLAN.md) as next increments.
