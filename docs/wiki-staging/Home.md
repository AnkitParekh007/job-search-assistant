# Job Search Assistant

A local-first desktop app for people who refuse auto-apply bots. Files stay in a folder you choose. You submit every application yourself.

The public app is **macOS Apple Silicon**, release [v0.1.5](https://github.com/AnkitParekh007/job-search-assistant/releases/tag/v0.1.5). It is ad-hoc signed, not notarized. First launch: right-click the app, then Open. Do not turn Gatekeeper off. Intel Mac and Windows are build-from-source.

AI features use your own Claude Code, Codex, OpenAI, Gemini, or Ollama setup. Capability varies. Tracking works with no provider.

## What this app does not do

- It does not submit applications or send email.
- It does not promise interviews, replies, or a pass through a screening system.
- There is no downloadable Intel or Windows app in the current release.
