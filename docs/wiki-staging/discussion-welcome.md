# Welcome to Job Search Assistant

This project is a local-first desktop app. The public binary is macOS Apple Silicon. Windows and Intel Mac are build-from-source. AI features use your own Claude Code, Codex, OpenAI, Gemini, or Ollama setup. Capability varies. Offline tracking needs no provider. The app does not submit applications for you.

- Docs: https://github.com/AnkitParekh007/job-search-assistant/blob/main/docs/getting-started.md
- Please keep personal job data out of public posts
- Provider usage consumes your own plan or API credits. Ollama can stay on this machine.
