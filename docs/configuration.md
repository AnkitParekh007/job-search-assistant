# Configuration

## Workspace

Choose any local folder during onboarding or in **Settings → Workspace**. If starter files are missing, Jobzuu creates them (including `CLAUDE.md`, tracker CSV, and profile stubs) without overwriting existing content. That folder is the source of truth for profile, jobs, and application files.

## AI Providers

Open **Settings → AI Providers** to pick a default engine (Claude Code, OpenAI Codex, OpenAI Platform API, Gemini, or Ollama). API keys stay in the OS keychain. Provider usage bills against your plan or API credits.

## Dependencies

**Settings → Dependencies** lists CLIs and optional tools. Agent workflows (Add portal, setup, scrape, …) run inside the app. System package installs (brew, TeX, …) stay manual in Terminal.
