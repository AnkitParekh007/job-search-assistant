# Screenshots checklist

Real application screenshots are **not** checked in yet. Do not fabricate UI captures.

## Capture rules

- Use the Apple Silicon build with **sample / sanitized** upstream data only
- Blur or avoid: real employer names you care about, emails, phone numbers, full resume text, tokens
- Prefer light theme for README consistency unless documenting dark mode
- Export PNG or WebP; keep longest edge ≤ 1600px for docs
- File naming: `01-today.png`, `02-jobs.png`, …
