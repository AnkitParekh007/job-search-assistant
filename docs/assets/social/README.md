# Social preview assets

| File | Size | Use |
|------|------|-----|
| `github-social-preview.png` | 1280×640 | GitHub repository **Social preview** upload |
| `social-preview.svg` | vector | Lightweight README / docs fallback |

## Manual GitHub step

1. Open https://github.com/AnkitParekh007/job-search-assitant/settings
2. **General → Social preview → Edit → Upload image**
3. Select `github-social-preview.png`

Requires repository admin access.
