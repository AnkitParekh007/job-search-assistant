# GitHub Discussions setup

**Status at audit:** `has_discussions: false` (public API).

## Enable (owner)

1. Repository **Settings → General → Features → Discussions**
2. Create categories (suggested):

| Category | Format | Purpose |
|----------|--------|---------|
| Announcements | Announcement | Maintainer releases / breaking notes |
| General | Discussion | Open chat |
| Ideas | Discussion | Lightweight brainstorming (promote solid ideas to Issues) |
| Q&A | Q&A | Support questions |
| Show and Tell | Discussion | Setups / workflows (sanitize personal data) |
| Feature Requests | Discussion | Optional — prefer Issues for actionable work |

## Starter posts (publish only when Discussions is on)

Drafts live in [`wiki-staging/`](./wiki-staging/) as discussion drafts:

- `discussion-welcome.md`
- `discussion-feature-ideas.md`
- `discussion-roadmap.md`
- `discussion-contributing.md`

Do not fake replies or community participation.
