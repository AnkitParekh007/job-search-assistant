# Roadmap

Derived from [`IMPLEMENTATION-PLAN.md`](../apps/macos-apple-silicon/docs/IMPLEMENTATION-PLAN.md) and gaps in the feature parity matrix. Dates are not commitments.

## Near-term

- Application Studio review visibility improvements
- Native Gmail proposal review UI (structured table vs console-only)
- Portal manager (list skills, enable/disable, review before install)
- Backup / restore of tracker, archives, and profile
- Desktop end-to-end tests (WebDriver / similar)
- In-app `.tex` edit + live recompile (stretch within Studio)

## Medium-term

- Distraction-free interview workspace + practice history
- Keyboard accessibility pass
- Integration status panels (Gmail / Notion connection health)
- App packaging and release automation (unsigned → signed/notarized path)

## Future

- macOS Intel release verification and artifacts
- Windows release verification and artifacts
- Additional AI provider support **only if** explicitly approved and designed
- Richer visual automation controls / skill-gap charts from `/upskill`

## Explicitly out of scope (current product)

- Browser / web application client
- Fully autonomous employer submission
- Claiming multi-platform “production complete” without release evidence
- Bundling or relicensing upstream source without attribution review
