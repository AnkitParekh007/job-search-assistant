# Description

```text
I got tired of auto-apply bots, so I built a local job-search desktop app that will not apply for you.

Job Search Assistant is free and MIT-licensed. Discover roles, rank fit (including the gaps), draft a CV only after you approve the file write, and track the pipeline yourself. Files stay in a folder on your machine.

The recording uses the fictional demo workspace in the repo. Nordlicht and the other names are sample data. The score on screen is that sample, not a result from a real search.

What it does not do:
• It does not submit applications
• It does not send email
• It does not promise interviews, replies, or a pass through anyone’s screening system

Download (macOS Apple Silicon, ad-hoc signed, not notarized — right-click → Open the first time):
https://github.com/AnkitParekh007/job-search-assistant/releases/tag/v0.1.5

Intel Mac and Windows: build from source. Do not disable Gatekeeper.
https://github.com/AnkitParekh007/job-search-assistant

AI features use your own Claude Code, Codex, OpenAI, Gemini, or Ollama setup. Capability varies by workflow. Tracking works with no provider.

Site: https://job-search-assistant.rebound-ops.org/
```
