A desktop command center for your job search

AI Job Search is a local-first macOS app that drives your existing ai-job-search workspace through Claude Code — so discovery, ranking, applications, and tracking stay on files you own.

No reimplemented agents in the cloud. Your signed-in Claude Code CLI runs the real upstream workflows. The app is the native shell.

How it works

You stay in control. Claude does the heavy lifting.

Point the app at your workspace, keep Claude Code signed in, and launch workflows from a clear pipeline: discover → rank → apply → outcome.

Sensitive actions ask for approval. Write and exec tools are never auto-approved. Credentials stay with Claude Code — not inside the app.
