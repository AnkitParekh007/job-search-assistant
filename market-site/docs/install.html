App install

There is no published GitHub Release binary yet. Build locally with Tauri, then open the .app. Drag it to /Applications if you want it to stay. Personal builds are typically unsigned — first launch may need right-click → Open.

Build from source

cd apps/macos-apple-silicon
npm install
npm test
npm run tauri build
open "src-tauri/target/release/bundle/macos/AI Job Search.app"

The bundle lands under src-tauri/target/release/bundle/macos/. Full guide: repository docs/installation.md.
