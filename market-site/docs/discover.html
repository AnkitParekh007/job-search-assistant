Discover & rank

Find new roles, dedupe them locally, then score what fits.

Discover jobs

Run Discover jobs (/scrape) from Workflows or Jobs. It uses installed portal CLIs when available, otherwise web search, and writes to job_scraper/seen_jobs.json.

Optional focus argument examples: a specialty, broad, or health.

Rank matches

Run Rank matches (/rank). Upstream fetches postings, runs the integrity gate, scores against your profile rubric, and returns a shortlist in the same local store.

Review in Jobs

  • Filter and compare roles in the Jobs screen.
  • Open a posting into Studio when you want tailored documents.
  • Watch Agent Activity while a scrape or rank run is live.
Failed runs stay honest. Terminal failures clear from the live badge and show retry/resume actions instead of fake progress.
