First run

Workspace, profile setup, and dependency health.

Choose a workspace

The app needs a local ai-job-search checkout. Onboarding detects a default path or lets you pick another folder. Settings → Workspace can change it later and reveal it in Finder.

Complete profile setup

Use /setup to import a CV, point at a documents folder, or answer a short interview. You can re-run sections:

  • /setup --section skills
  • /setup --section experience
  • /setup --section search

Verify dependencies

Open Settings → Dependencies and click Re-check. Fix anything red before scraping or drafting — especially Claude Code sign-in and LaTeX for PDFs.

Skip is allowed. You can skip setup and fill Profile later, but ranking and apply quality depend on a grounded profile.
