# Apps

Native and web clients for **AI Job Search**. Each folder is the home for that platform’s product code and release artifacts.

| App | Path | Target |
|-----|------|--------|
| macOS Apple Silicon | [`macos-apple-silicon/`](./macos-apple-silicon/) | arm64 (`M1`–`M4`) |
| macOS Intel | [`macos-intel/`](./macos-intel/) | x86_64 (Intel Macs) |
| Windows | [`windows/`](./windows/) | Windows desktop |
| Web | [`web/`](./web/) | Browser app |

Marketing and docs live in [`../market-site/`](../market-site/), not here.
